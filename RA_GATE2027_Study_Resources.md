# GATE 2027 RA — Study Resources by Topic

Every resource below is a clickable link. Direct links go to the official site; the rest are search links (YouTube, NPTEL via Google, MIT OCW search, or Google for book PDFs/notes), so they always open and never go stale. Pick the top result by the IIT / MIT / named author.

**Practice for everything:** GATE previous-year papers (RA is new, so also use ME/EE/IN/PI/CS papers per topic), NPTEL assignments, topic-wise mock tests.

## Suggested order (fast path)
1. Engg Math + Signals + Control (heaviest, shared across papers)
2. Robotics kinematics (rotation matrices, DH, FK) — RA-specific, high value
3. Circuits / analog / digital / microcontrollers
4. Mechanics of materials, kinematics & dynamics, machine design
5. Python + data structures, PLC/CIM, sensors/actuators
6. Previous papers + mock tests

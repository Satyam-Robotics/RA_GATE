Part A.1 — Engineering Mathematics

1. Linear Algebra

Matrix basics

  • Transpose: (Aᵀ)ᵢⱼ = Aⱼᵢ; (AB)ᵀ = BᵀAᵀ; (A⁻¹)ᵀ = (Aᵀ)⁻¹.
  • Symmetric: Aᵀ = A. Skew-symmetric: Aᵀ = −A (diagonal = 0; odd order ⇒ det = 0). Any A = ½(A+Aᵀ) + ½(A−Aᵀ).
  • Orthogonal: AᵀA = I ⇒ A⁻¹ = Aᵀ, det = ±1, columns orthonormal. Rotation matrices are orthogonal with det = +1.
  • Trace: sum of diagonal = sum of eigenvalues; tr(AB) = tr(BA).
  • Adjoint: adj(A) = transpose of cofactor matrix. A·adj(A) = det(A)·I ⇒ A⁻¹ = adj(A)/det(A). det(adj A) = (det A)ⁿ⁻¹ for n×n. adj(adj A) = (det A)ⁿ⁻²·A.

Determinant

  • det(AB) = det A·det B; det(Aᵀ) = det A; det(kA) = kⁿ det A; det(A⁻¹) = 1/det A.
  • Swapping two rows changes sign; adding a multiple of one row to another leaves det unchanged; two equal/proportional rows ⇒ det = 0.
  • Triangular matrix: det = product of diagonal. det = product of eigenvalues.

Rank

  • Rank = number of linearly independent rows (= columns) = number of non-zero rows in row-echelon form = order of largest non-zero minor.
  • rank(AB) ≤ min(rank A, rank B). rank(A) = rank(Aᵀ). Rank–nullity: rank + nullity = n (number of columns).

  • Methods: Gaussian elimination, Gauss–Jordan, Cramer's rule (xᵢ = det Aᵢ / det A), LU decomposition.

Eigenvalues and eigenvectors

  • Ax = λx, x ≠ 0. Characteristic equation: det(A − λI) = 0.
  • Σλᵢ = trace, Πλᵢ = det. Eigenvalues of triangular/diagonal matrix = diagonal entries.
  • Eigenvalues of A⁻¹: 1/λ; Aᵏ: λᵏ; A + kI: λ + k; kA: kλ; Aᵀ: same λ. Eigenvectors stay the same (except for Aᵀ).
  • Real symmetric ⇒ real eigenvalues, orthogonal eigenvectors. Skew-symmetric ⇒ zero or purely imaginary. Orthogonal ⇒ |λ| = 1.
  • Distinct eigenvalues ⇒ linearly independent eigenvectors ⇒ diagonalizable: A = PDP⁻¹.
  • Cayley–Hamilton: every matrix satisfies its own characteristic equation (useful to find A⁻¹ and powers).
  • Algebraic multiplicity ≥ geometric multiplicity (= n − rank(A − λI)).

2. Calculus

Limits, continuity, differentiability

  • Limit exists iff LHL = RHL. Continuous at a iff limx→a f(x) = f(a).
  • Differentiable ⇒ continuous (not conversely; e.g. |x| at 0).
  • Standard limits: sin x/x → 1; (1 + x)1/x → e; (eˣ − 1)/x → 1; (aˣ − 1)/x → ln a; (1 + 1/x)ˣ → e as x→∞.

Mean value theorems

  • Rolle: f continuous on [a,b], differentiable on (a,b), f(a) = f(b) ⇒ ∃ c: f′(c) = 0.
  • Lagrange (MVT): ∃ c ∈ (a,b): f′(c) = [f(b) − f(a)]/(b − a).
  • Cauchy: [f(b) − f(a)]/[g(b) − g(a)] = f′(c)/g′(c).

Indeterminate forms

  • 0/0, ∞/∞ → L'Hôpital: lim f/g = lim f′/g′.
  • 0·∞ → rewrite as 0/0. ∞ − ∞ → combine into one fraction. 1^∞, 0⁰, ∞⁰ → take log: L = elim g·ln f. For 1^∞: L = elim g(f − 1).

Integrals

  • ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a − x)dx. ∫₋ₐᵃ f dx = 2∫₀ᵃ f (even) or 0 (odd).
  • Wallis: ∫₀^{π/2} sinⁿx dx = [(n−1)(n−3).../n(n−2)...] × (π/2 if n even, 1 if n odd).
  • Improper integrals: infinite limits or unbounded integrand; evaluate as a limit. ∫₁^∞ 1/xᵖ dx converges iff p > 1; ∫₀¹ 1/xᵖ dx converges iff p < 1.
  • Gamma: Γ(n) = ∫₀^∞ e⁻ˣxⁿ⁻¹dx, Γ(n+1) = nΓ(n) = n!, Γ(½) = √π. ∫₀^∞ e^{−x²}dx = √π/2.

Double and triple integrals

  • Change order of integration by redrawing the region. Polar: dx dy = r dr dθ. Cylindrical: r dr dθ dz. Spherical: r² sin φ dr dθ dφ.
  • Area = ∬ dx dy; volume = ∭ dV; general change of variables uses the Jacobian |∂(x,y)/∂(u,v)|.

Partial and total derivatives

  • Total differential: du = (∂u/∂x)dx + (∂u/∂y)dy. Chain rule: du/dt = ux·dx/dt + uy·dy/dt.
  • Euler's theorem (u homogeneous of degree n): x ux + y uy = n u; second order: x²uxx + 2xy uxy + y²uyy = n(n−1)u.
  • Implicit: dy/dx = −fx/fy.

Taylor series

  • One variable: f(a+h) = f(a) + h f′(a) + h²/2! f″(a) + … Maclaurin at a = 0.
  • Key series: eˣ = Σxⁿ/n!; sin x = x − x³/3! + x⁵/5! − …; cos x = 1 − x²/2! + x⁴/4! − …; ln(1+x) = x − x²/2 + x³/3 − …; 1/(1−x) = 1 + x + x² + … (|x| < 1).
  • Two variables: f(a+h, b+k) = f + (h fx + k fy) + (1/2!)(h² fxx + 2hk fxy + k² fyy) + …

Maxima and minima

  • One variable: f′ = 0; f″ < 0 ⇒ max, f″ > 0 ⇒ min, f″ = 0 ⇒ check higher derivatives.
  • Two variables: fx = fy = 0. r = fxx, s = fxy, t = fyy. rt − s² > 0 and r < 0 ⇒ max; rt − s² > 0 and r > 0 ⇒ min; rt − s² < 0 ⇒ saddle; = 0 ⇒ inconclusive.
  • Constrained: Lagrange multipliers, ∇f = λ∇g.

Vector calculus

  • Gradient ∇φ: vector normal to level surface; directional derivative = ∇φ·â; maximum rate = |∇φ|.
  • Divergence ∇·F = ∂F₁/∂x + ∂F₂/∂y + ∂F₃/∂z (scalar). ∇·F = 0 ⇒ solenoidal.
  • Curl ∇×F (vector). ∇×F = 0 ⇒ irrotational (conservative, F = ∇φ).
  • Identities: ∇×(∇φ) = 0; ∇·(∇×F) = 0; ∇·(φF) = φ∇·F + F·∇φ; ∇×(φF) = φ∇×F + ∇φ×F; ∇×(∇×F) = ∇(∇·F) − ∇²F; ∇·r = 3, ∇×r = 0, ∇rⁿ = n rⁿ⁻² r.
  • Green: ∮(M dx + N dy) = ∬(∂N/∂x − ∂M/∂y) dA. Stokes: ∮F·dr = ∬(∇×F)·n dS. Gauss divergence: ∯F·n dS = ∭∇·F dV.

3. Differential Equations

First order

  • Variable separable: f(x)dx = g(y)dy.
  • Homogeneous dy/dx = f(y/x): put y = vx.
  • Exact: M dx + N dy = 0 exact iff ∂M/∂y = ∂N/∂x. Solution: ∫M dx (y const) + ∫(terms of N without x) dy = c. Integrating factors: (My − Nx)/N = f(x) ⇒ IF = e∫f dx.
  • Linear: y′ + P(x)y = Q(x). IF = e∫P dx; y·IF = ∫Q·IF dx + c.
  • Bernoulli (nonlinear): y′ + Py = Qyⁿ; put z = y1−n to make it linear.

Higher order linear with constant coefficients

  • Solution y = C.F. + P.I. Auxiliary equation from D → m.
  • C.F.: distinct real roots → Σcᵢemᵢx; repeated root m → (c₁ + c₂x)emx; complex α ± iβ → eαx(c₁cos βx + c₂sin βx).
  • P.I.: eax → eax/f(a) (if f(a) = 0, multiply by x and differentiate f). sin ax, cos ax → replace D² by −a². xⁿ → expand [f(D)]⁻¹ as a power series. eaxV → eax·[1/f(D+a)]V.

Euler–Cauchy equation

  • x²y″ + a x y′ + b y = R(x). Substitute x = eᵗ (xD = θ, x²D² = θ(θ−1)) → constant-coefficient ODE in t.
  • Equivalently try y = xᵐ: m(m−1) + am + b = 0. Repeated root m ⇒ y = (c₁ + c₂ ln x)xᵐ.

IVP and BVP

  • IVP: conditions at one point (y(x₀), y′(x₀)). BVP: conditions at two points; may have no or infinitely many solutions.

  • Parseval: (1/L)∫f² = a₀²/2 + Σ(aₙ² + bₙ²).

4. Probability and Statistics

  • Axioms: P(A) ≥ 0; P(S) = 1; for disjoint events P(A∪B) = P(A) + P(B).
  • P(A∪B) = P(A) + P(B) − P(A∩B). Independent ⇒ P(A∩B) = P(A)P(B).
  • Conditional: P(A|B) = P(A∩B)/P(B). Total probability: P(B) = ΣP(B|Aᵢ)P(Aᵢ). Bayes: P(Aᵢ|B) = P(B|Aᵢ)P(Aᵢ)/ΣP(B|Aⱼ)P(Aⱼ).
  • Central tendency: mean = Σx/n; median = middle value; mode = most frequent. Empirical: mode ≈ 3 median − 2 mean.
  • Dispersion: variance σ² = E[X²] − (E[X])²; SD = σ. Var(aX + b) = a²Var(X).
  • Random variable: discrete (PMF) or continuous (PDF). PDF f(x) ≥ 0, ∫f = 1, P(a<X<b) = ∫ₐᵇ f. CDF F(x) = P(X ≤ x), non-decreasing, F(−∞) = 0, F(∞) = 1, f = F′.
  • E[X] = Σx p(x) or ∫x f(x) dx; E[aX + bY] = aE[X] + bE[Y].

5. Numerical Methods

Algebraic and transcendental equations

  • Bisection: f(a)f(b) < 0, halve the interval; linear convergence; error after n steps ≤ (b−a)/2ⁿ.
  • Regula falsi: x = (a f(b) − b f(a))/(f(b) − f(a)).
  • Newton–Raphson: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ); quadratic convergence (order 2). Square root of N: xₙ₊₁ = ½(xₙ + N/xₙ).
  • Secant: order ≈ 1.618. Fixed-point x = g(x) converges if |g′(x)| < 1.
  • Linear systems: Gauss elimination (direct); Jacobi and Gauss–Seidel (iterative, converge if diagonally dominant; Gauss–Seidel faster).

Finite differences

  • Forward Δy = y₁ − y₀; backward ∇y = y₁ − y₀ (at y₁); central δ. Shift E = 1 + Δ.
  • f′(x) ≈ [f(x+h) − f(x)]/h (O(h)); central [f(x+h) − f(x−h)]/2h (O(h²)); f″ ≈ [f(x+h) − 2f(x) + f(x−h)]/h².

ODE solvers for y′ = f(x, y)

  • Explicit Euler: yₙ₊₁ = yₙ + h f(xₙ, yₙ) — first order, local error O(h²), global O(h).
  • Modified Euler / Heun: predictor-corrector, second order.
  • RK4: k₁ = hf(x,y); k₂ = hf(x+h/2, y+k₁/2); k₃ = hf(x+h/2, y+k₂/2); k₄ = hf(x+h, y+k₃); yₙ₊₁ = yₙ + (k₁ + 2k₂ + 2k₃ + k₄)/6. Fourth order.
  • Multi-step: Adams–Bashforth (explicit), Adams–Moulton (implicit), Milne's predictor-corrector — use several previous points.
  • Stability: explicit Euler for y′ = λy stable if |1 + hλ| ≤ 1.

Part A.2 — Basics of Mechatronics

1. Network Elements and Analysis

Elements and sources

  • Ideal voltage source: fixed V, zero internal resistance (practical: series R). Ideal current source: fixed I, infinite internal resistance (practical: parallel R).
  • Dependent sources: VCVS, VCCS, CCVS, CCCS. Do not switch them off when finding Rth; use a test source instead.
  • R: v = iR, P = i²R. L: v = L di/dt, energy ½Li², current cannot change instantly, acts as a short at DC. C: i = C dv/dt, energy ½Cv², voltage cannot change instantly, acts as an open at DC.
  • Series R add; parallel 1/R add. Inductors combine like R; capacitors combine the opposite way. M (mutual inductance): v₂ = M di₁/dt; M = k√(L₁L₂); series aiding L = L₁ + L₂ + 2M, opposing L₁ + L₂ − 2M.
  • Voltage divider: Vₓ = V·Rₓ/ΣR. Current divider: I₁ = I·R₂/(R₁ + R₂).
  • Star–delta: RY = RabRac/ΣRΔ; balanced RY = RΔ/3.

Kirchhoff's laws and solution methods

  • KCL: Σ currents into a node = 0 (charge conservation). KVL: Σ voltages around a loop = 0 (energy conservation).
  • Nodal analysis: pick a reference node, write KCL at the other (n − 1) nodes in terms of node voltages. A voltage source between two non-reference nodes forms a supernode.
  • Mesh analysis: write KVL around b − n + 1 meshes (planar circuits). A current source shared by two meshes forms a supermesh.

Network theorems

  • Thevenin: any linear two-terminal network = Vth (open-circuit voltage) in series with Rth (sources off: V → short, I → open).
  • Norton: IN (short-circuit current) in parallel with RN = Rth. Vth = INRth.
  • Superposition: response = sum of responses to each independent source acting alone (linear circuits only; not valid for power).
  • Maximum power transfer: DC: RL = Rth, Pmax = Vth²/4Rth, efficiency 50%. AC: ZL = Zth* (conjugate); if only |ZL| can vary, RL = |Zth|.
  • Also know: reciprocity, Tellegen (Σvᵢiᵢ = 0), Millman.

Transient response

  • First order: x(t) = x(∞) + [x(0⁺) − x(∞)]e−t/τ. τ = RC or L/R (R = Thevenin resistance seen by C or L).
  • After 5τ the response is >99% settled. RC charging: vC = V(1 − e−t/RC).
  • Second-order series RLC: s² + (R/L)s + 1/LC = 0. ω₀ = 1/√LC, ζ = (R/2)√(C/L). ζ > 1 overdamped, = 1 critically damped, < 1 underdamped (oscillatory with ωd = ω₀√(1−ζ²)).
  • Parallel RLC: ζ = (1/2R)√(L/C).

Sinusoidal steady state

  • Phasor: v = Vmcos(ωt + φ) → V∠φ. Impedances: ZR = R, ZL = jωL, ZC = 1/jωC.
  • RMS of sinusoid = Vm/√2. Current lags voltage in an inductive circuit, leads in a capacitive circuit.
  • Complex power: S = V I* = P + jQ. P = VrmsIrmscos φ (W), Q = VrmsIrmssin φ (VAR), |S| (VA). Power factor = cos φ = P/|S|. PF correction adds a shunt capacitor: QC = P(tan φ₁ − tan φ₂).

Resonance

  • Series RLC: ω₀ = 1/√LC; Z = R (minimum), current maximum, PF = 1. Q = ω₀L/R = (1/R)√(L/C). Bandwidth = R/L = ω₀/Q. Voltage across L or C = Q × supply voltage.
  • Parallel RLC: impedance maximum, current minimum. Q = R√(C/L). BW = 1/RC.
  • Half-power frequencies: ω₁ω₂ = ω₀².

2. Digital Circuits

Boolean algebra

  • Laws: identity (A + 0 = A, A·1 = A), null (A + 1 = 1, A·0 = 0), idempotent, complement (A + A′ = 1), absorption (A + AB = A, A(A + B) = A), A + A′B = A + B.
  • De Morgan: (A + B)′ = A′B′; (AB)′ = A′ + B′. Consensus: AB + A′C + BC = AB + A′C.
  • SOP (minterms Σm) and POS (maxterms ΠM). K-maps: group 1s in powers of 2 (adjacent wraps around); don't-cares can be used for larger groups.
  • NAND and NOR are universal gates. XOR: A ⊕ B = A′B + AB′; XNOR is equality. A ⊕ A = 0, A ⊕ 1 = A′.
  • Number systems: binary, octal, hex, BCD, Gray (gᵢ = bᵢ ⊕ bᵢ₊₁). 2's complement: invert and add 1; n-bit range −2ⁿ⁻¹ to 2ⁿ⁻¹ − 1.

Combinational circuits

  • Half adder: S = A ⊕ B, C = AB. Full adder: S = A ⊕ B ⊕ Cᵢₙ, C = AB + Cᵢₙ(A ⊕ B).
  • Multiplexer (2ⁿ:1): n select lines choose one of 2ⁿ inputs. A 2ⁿ:1 MUX can implement any n-variable function (or n+1 variables using the last variable at data inputs).
  • Demultiplexer: one input to one of 2ⁿ outputs.
  • Decoder (n → 2ⁿ): activates one output per input code; decoder + OR gate implements any SOP.
  • Encoder (2ⁿ → n): inverse; priority encoder outputs the highest-priority active input.
  • Comparators, code converters, parity generators.

3. Sensors and Signal Conditioning

  • Static characteristics: accuracy, precision, resolution, sensitivity (Δoutput/Δinput), linearity, hysteresis, range/span, drift, dead zone. Dynamic: response time, time constant, bandwidth.
  • Resistive: potentiometer (displacement, Vout = V·x/L; loading error when meter R is finite), strain gauge (gauge factor GF = (ΔR/R)/ε ≈ 2 for metals), RTD (R = R₀(1 + αT), platinum Pt100), thermistor (NTC, nonlinear, R = R₀eβ(1/T − 1/T₀)), LDR.
  • Capacitive: C = εA/d. Vary d (nonlinear, high sensitivity), A (linear) or ε (level sensing). Differential arrangement improves linearity.
  • Inductive: variable reluctance, LVDT (primary + two secondaries in series opposition; output ∝ displacement, phase gives direction; null at centre; needs phase-sensitive demodulation). RVDT for angle.
  • Piezoelectric: charge q = d·F (d = charge sensitivity, C/N). Only for dynamic (not static) measurement because charge leaks. Needs a charge amplifier. Used in accelerometers, force/pressure sensors.
  • Hall effect: VH = BI/(n q t). Used for proximity, current, speed sensing, BLDC commutation.
  • Thermocouple: Seebeck effect, needs cold-junction compensation.

Signal conditioning

  • Wheatstone bridge: balanced when R₁R₄ = R₂R₃. Quarter bridge (1 active gauge): Vo ≈ V·GF·ε/4; half bridge ×2; full bridge (4 active): V·GF·ε. Dummy gauge for temperature compensation.
  • Instrumentation amplifier (high CMRR, high input impedance), filtering, linearization, isolation, ADC, excitation, cold-junction compensation, demodulation.

4. Actuators

Hydraulic and pneumatic

  • Pascal's law: pressure transmitted equally; F = pA. Cylinder extend force = pAbore; retract force = p(Abore − Arod). Velocity = Q/A. Power = pQ.
  • Hydraulic: incompressible oil, high force/power density, stiff, precise, but leaks and needs a pump and reservoir. Typical pressure 70–350 bar.
  • Pneumatic: compressed air (~6–8 bar), fast, clean, cheap, compliant; poor position control due to compressibility.
  • Components: pumps (gear, vane, piston), cylinders (single/double acting), motors, directional control valves (e.g. 4/3, 5/2: ports/positions), pressure relief valve, flow control valve, check valve, servo and proportional valves, accumulator.
  • Hydraulic motor torque T = pD/(2π) (D = displacement per rev); speed N = Q/D.

DC motors

  • Back-EMF Eb = kφω; V = Eb + IaRa; torque T = kφIa. Power: EbIa = Tω.
  • Permanent magnet / separately excited: ω = V/kφ − RaT/(kφ)² — linear drooping torque-speed line. Stall torque at ω = 0; no-load speed at T = 0. Max power at half the no-load speed.
  • Series motor: T ∝ I² (high starting torque, dangerous at no load). Shunt: nearly constant speed.
  • Speed control: armature voltage (below base speed), field weakening (above base speed). PWM with an H-bridge for direction.
  • Transfer function θ(s)/V(s) = K/[s(Js + b)(Ls + R) + K²] ≈ Km/[s(τms + 1)].

Stepper motors

  • Step angle = 360°/(2m·Nr) for PM/hybrid (m = phases, Nr = rotor teeth or pole pairs; e.g. 2-phase hybrid with 50 teeth → 1.8°); variable reluctance: (Ns − Nr)/(NsNr) × 360°.
  • Steps/rev = 360°/step angle. Speed (rpm) = (step rate × step angle × 60)/360.
  • Types: permanent magnet, variable reluctance, hybrid (typically 1.8°). Drive modes: full step, half step (doubles resolution), microstepping.
  • Open-loop positioning; holding torque, detent torque, pull-in and pull-out torque curves; can lose steps or resonate.

Servo motors

  • Motor + feedback sensor (encoder/resolver/potentiometer) + controller in a closed loop. DC servo, AC servo (BLDC/PMSM), RC servo (PWM: 1–2 ms pulse every 20 ms sets angle).
  • BLDC: electronic commutation using Hall sensors; high efficiency, no brush wear.
  • AC induction motor: synchronous speed Nₛ = 120f/P; slip s = (Nₛ − N)/Nₛ.

5. Engineering Mechanics

Free-body diagrams and equilibrium

  • FBD: isolate the body, show all external forces and moments (weights, reactions, friction, applied loads).
  • 2D equilibrium: ΣFx = 0, ΣFy = 0, ΣM = 0 (3 equations). 3D: 6 equations.
  • Supports: roller (1 reaction), pin/hinge (2), fixed (3 incl. moment).
  • Lami's theorem (3 concurrent forces): F₁/sin α = F₂/sin β = F₃/sin γ (angle opposite each force). Two-force member: forces equal, opposite, collinear.
  • Varignon: moment of resultant = sum of moments of components. Couple: moment independent of point.
  • Virtual work: ΣF·δr = 0 for equilibrium.

Friction

  • Coulomb: F ≤ μsN; sliding F = μkN (μk < μs). Angle of friction tan φ = μ = angle of repose.
  • Block on incline: slides if tan θ > μ. Force up the incline P = W(sin θ + μ cos θ); to prevent sliding down P = W(sin θ − μ cos θ).
  • Wedges, screw jack: effort P = W tan(α + φ); self-locking if φ > α; efficiency = tan α/tan(α + φ).
  • Rolling friction: resistance F = W·a/r (a = coefficient of rolling resistance, length units). Much smaller than sliding friction.
  • Belt friction: T₁/T₂ = eμθ (θ in radians, T₁ tight side). V-belt: eμθ/sin(β/2). Power = (T₁ − T₂)v. With centrifugal tension Tc = mv², max power when Tc = Tmax/3. Open belt vs crossed belt lengths; crossed belt reverses direction.

Trusses and frames

  • Truss: two-force members joined by pins, loads at joints. Simple (perfect) plane truss: m = 2j − 3. m < 2j − 3 → mechanism; m > 2j − 3 → statically indeterminate.
  • Method of joints: equilibrium at each joint (2 equations, ≤2 unknowns). Method of sections: cut through ≤3 members, use 3 equations.
  • Zero-force members: at an unloaded joint with two non-collinear members, both are zero; with three members where two are collinear, the third is zero.
  • Frames/machines contain multi-force members; disassemble and apply equilibrium to each part.

Kinematics of rigid bodies (plane motion)

  • Particle: v = u + at; s = ut + ½at²; v² = u² + 2as. Projectile: range = u²sin 2θ/g; max height = u²sin²θ/2g; time = 2u sin θ/g.
  • Circular: v = ωr; at = αr; an = ω²r = v²/r.
  • Rigid body: vB = vA + ω × rB/A; aB = aA + α × rB/A − ω²rB/A.
  • Instantaneous centre (IC): point of zero velocity; v = ω × (distance from IC). Rolling without slipping: vcentre = ωR, contact point at rest, top point 2v.

Dynamics of rigid bodies

  • ΣF = m aG; ΣMG = IGα. D'Alembert: add inertia force −ma and inertia torque −Iα, then treat as statics.
  • Moments of inertia: rod about centre mL²/12, about end mL²/3; disc mR²/2; ring mR²; solid sphere 2mR²/5. Parallel axis I = IG + md².
  • Work–energy: KE = ½mvG² + ½IGω². Rolling down incline: a = g sin θ/(1 + k²/R²).
  • Impulse–momentum: ∫F dt = Δ(mv); angular momentum H = Iω conserved if no external torque. Coefficient of restitution e = (v₂ − v₁)/(u₁ − u₂).

Part A.3 — Principles of Robotics and Automation

1. Robot Classification

  • Serial manipulator: open kinematic chain, one path from base to end-effector. Large workspace, dexterous, but errors accumulate along the chain and stiffness/payload is lower. Forward kinematics easy, inverse kinematics hard (multiple solutions).
  • Parallel manipulator: closed chains; the end-effector (platform) is connected to the base by several legs (e.g. Stewart–Gough platform 6-DOF, Delta robot 3-DOF translation). High stiffness, accuracy, speed, payload-to-weight ratio; small workspace. Inverse kinematics easy, forward kinematics hard.
  • Other classifications: by drive (electric, hydraulic, pneumatic), by control (point-to-point, continuous path, servo/non-servo), by application (industrial, mobile, service), by generation/intelligence.

2. Links, Joints, Coordinate Systems and DOF

  • Link: rigid body. Joint: connection allowing relative motion.
  • Lower pairs: revolute R (1 DOF), prismatic P (1), helical/screw H (1), cylindrical C (2), spherical S (3), planar E (3). Universal joint U (2).
  • DOF of a rigid body: 3 in a plane, 6 in space (3 position + 3 orientation).
  • Grübler–Kutzbach (mobility): planar M = 3(n − 1) − 2j₁ − j₂; spatial M = 6(n − 1) − Σ(6 − fᵢ) (n = links incl. ground, j₁ = 1-DOF joints, j₂ = 2-DOF joints, fᵢ = DOF of joint i).
  • A serial arm's DOF = sum of joint DOFs. 6 DOF are needed for arbitrary position and orientation; >6 is redundant (e.g. 7-DOF arms; avoid obstacles/singularities).
  • Typical arm: 3 joints for position (arm) + 3 for orientation (wrist: roll–pitch–yaw / spherical wrist with intersecting axes).
  • Coordinate frames: world/base frame, joint frames, tool (TCP) frame, user/workpiece frame. Joint space (θ₁…θₙ) vs task/Cartesian space (x, y, z, orientation).
  • Workspace: reachable workspace (points reachable in at least one orientation) vs dexterous workspace (all orientations).
  • Singularity: configuration where the Jacobian loses rank (det J = 0): loss of a DOF, infinite joint velocities needed; e.g. a fully stretched arm or two aligned wrist axes.

3. Rotation Matrices

2D

  • R(θ) = [[cos θ, −sin θ], [sin θ, cos θ]]. Rotating a vector counter-clockwise by θ: p′ = R p.

3D elementary rotations

  • Rx(θ) = [[1, 0, 0], [0, cθ, −sθ], [0, sθ, cθ]]
  • Ry(θ) = [[cθ, 0, sθ], [0, 1, 0], [−sθ, 0, cθ]] (note the sign pattern)
  • Rz(θ) = [[cθ, −sθ, 0], [sθ, cθ, 0], [0, 0, 1]]

Properties (SO(3))

  • Columns of ARB are the unit axes of frame B expressed in frame A.
  • Orthogonal: Rᵀ R = I, R⁻¹ = Rᵀ, det R = +1. Each row/column is a unit vector, mutually perpendicular. Preserves lengths and angles.
  • Eigenvalues: 1, e±iθ. The eigenvector for λ = 1 is the rotation axis. trace R = 1 + 2 cos θ.
  • Composition: ARC = ARB BRC. Rotations about the current (moving) frame → post-multiply; about the fixed frame → pre-multiply. Matrix multiplication is not commutative.
  • Euler angles (ZYZ): R = Rz(φ)Ry(θ)Rz(ψ). Roll–pitch–yaw (fixed XYZ): R = Rz(α)Ry(β)Rx(γ). Both have singularities (gimbal lock).
  • Axis–angle (Rodrigues): R = I + sin θ [k]ₓ + (1 − cos θ)[k]ₓ². Quaternions avoid singularities: q = (cos θ/2, k sin θ/2).

4. Homogeneous Transformations

  • T = [[R, d], [0 0 0, 1]] (4×4), combining rotation R and translation d. Point in homogeneous form p̃ = [x, y, z, 1]ᵀ; Ap̃ = ATB Bp̃.
  • Inverse: T⁻¹ = [[Rᵀ, −Rᵀd], [0, 1]] (not simply the transpose).
  • Chain: 0Tn = 0T₁ 1T₂ … n−1Tn. Same pre/post-multiplication rule as for rotations.
  • Pure translation Trans(a, b, c) has R = I; pure rotation has d = 0.
  • Free vectors (directions) use a 0 as the fourth component, so translation does not affect them.

5. Forward Kinematics

  • Given joint variables, find end-effector position and orientation: 0Tn(q).
  • Denavit–Hartenberg (standard) convention: zᵢ along joint i+1 axis; xᵢ along the common normal from zᵢ₋₁ to zᵢ. Four parameters per link:
    • θᵢ — joint angle about zᵢ₋₁ (variable for revolute)
    • dᵢ — offset along zᵢ₋₁ (variable for prismatic)
    • aᵢ — link length along xᵢ
    • αᵢ — link twist about xᵢ
  • i−1Aᵢ = Rotz(θᵢ) Transz(dᵢ) Transx(aᵢ) Rotx(αᵢ) = [[cθ, −sθcα, sθsα, a cθ], [sθ, cθcα, −cθsα, a sθ], [0, sα, cα, d], [0, 0, 0, 1]].
  • 2-link planar arm (lengths L₁, L₂): x = L₁cos θ₁ + L₂cos(θ₁ + θ₂); y = L₁sin θ₁ + L₂sin(θ₁ + θ₂); orientation φ = θ₁ + θ₂. Workspace: annulus with radii |L₁ − L₂| and L₁ + L₂.
  • Inverse kinematics (2-link): cos θ₂ = (x² + y² − L₁² − L₂²)/(2L₁L₂) (two solutions: elbow up/down); θ₁ = atan2(y, x) − atan2(L₂ sin θ₂, L₁ + L₂ cos θ₂).
  • Jacobian: ẋ = J(q) q̇ relates joint velocities to end-effector velocity; τ = Jᵀ F relates end-effector force to joint torques. For the 2-link arm: J = [[−L₁s₁ − L₂s₁₂, −L₂s₁₂], [L₁c₁ + L₂c₁₂, L₂c₁₂]], det J = L₁L₂ sin θ₂ (singular at θ₂ = 0, π).

6. Robot Applications and Performance

  • Point-to-point (PTP) control: only the end points matter, path between them is not controlled (spot welding, pick-and-place, machine loading, drilling). Often joint-interpolated motion.
  • Continuous path (CP) control: the whole trajectory is controlled (arc welding, spray painting, gluing, deburring). Requires Cartesian interpolation (linear/circular) and coordinated joints.
  • Trajectory planning: cubic polynomial (4 constraints: positions and velocities at both ends), quintic (adds accelerations), linear segments with parabolic blends (LSPB/trapezoidal velocity).
  • Teaching/programming: lead-through, teach pendant, offline programming (simulation).
  • Applications: material handling, palletizing, machine tending, welding, painting, assembly, inspection, medical, space, underwater.

End-effectors

  • Grippers: mechanical (2/3-finger, parallel or angular jaws; friction grip μ·nf·Fg ≥ W × g-factor, nf = contact surfaces, g-factor accounts for acceleration), vacuum (suction cups; F = ΔP·A; flat, smooth parts), magnetic (electromagnet or permanent; ferrous parts), adhesive, soft/compliant, multi-fingered hands.
  • Tools: welding torch, spot-welding gun, spray gun, drill/spindle, screwdriver, laser/water-jet cutter.
  • Tool changers; Remote Centre Compliance (RCC) device for peg-in-hole assembly.

Accuracy, repeatability, resolution

  • Resolution (control resolution): smallest increment the controller can command; = range/2ⁿ for an n-bit encoder/control word.
  • Accuracy: how close the robot gets to a commanded target. Accuracy = ½ control resolution + ½ mechanical inaccuracy spread (3σ). Errors come from link deflection, gear backlash, calibration, thermal expansion.
  • Repeatability: how close the robot returns to a previously taught point (± 3σ of the spread). Industrial robots: repeatability (~±0.02–0.1 mm) is much better than absolute accuracy.
  • Other specs: payload, reach, speed, DOF, work envelope, compliance.

7. Computer Integrated Manufacturing (CIM)

Automation in manufacturing

  • Fixed (hard) automation: high volume, low variety, high initial cost (transfer lines). Programmable: batch production, reprogrammable (CNC, robots). Flexible: variety without lost changeover time (FMS).
  • Production metrics: cycle time Tc; production rate Rp = 1/Tp; utilization; availability A = (MTBF − MTTR)/MTBF; manufacturing lead time MLT = no(Tsu + Q Tc + Tno); WIP.
  • Levels of automation: device → machine → cell/system → plant → enterprise. Ten strategies: specialization of operations, combined operations, simultaneous operations, integration of operations, increased flexibility, improved material handling and storage, on-line inspection, process control and optimization, plant operations control, CIM.
  • Transfer line efficiency E = Tc/(Tc + F·Td) (F = breakdown frequency, Td = downtime). Line balancing: balance efficiency = Twc/(n × Ts).

Programmable Logic Controllers (PLCs)

  • Industrial computer: CPU, memory, input modules (sensors/switches), output modules (relay, transistor, triac), power supply, programming device; communication (Modbus, Profibus, EtherNet/IP).
  • Scan cycle: read inputs → execute program → update outputs → housekeeping/communication. Scan time typically ms; an input shorter than one scan can be missed.
  • IEC 61131-3 languages: Ladder Diagram (LD), Function Block Diagram (FBD), Structured Text (ST), Instruction List (IL), Sequential Function Chart (SFC).
  • Ladder logic: series contacts = AND, parallel contacts = OR, NC contact = NOT. Seal-in (latch) circuit for start/stop: (Start + Motor)·Stop′ → Motor.
  • Timers (TON on-delay, TOF off-delay, RTO retentive), counters (CTU, CTD), comparison/math, sequencers. Advantages over relays: reprogrammable, compact, diagnostics.

Automated material handling

  • Industrial trucks, AGVs (automated guided vehicles: wire/tape/laser/vision guidance; towing, unit-load, forklift types) and AMRs, conveyors (roller, belt, chain, overhead trolley, cart-on-track), cranes and hoists, monorails, industrial robots.
  • Principles: unit load, minimum handling, straight-line flow, standardization, gravity use. AGV system sizing: number of vehicles = total workload / available time per vehicle.

Automated storage and retrieval systems (AS/RS)

  • Storage racks + storage/retrieval (S/R) machines in aisles + pickup/deposit (P&D) stations, under computer control. Types: unit load, mini-load, man-on-board, deep-lane, carousel storage (horizontal/vertical).
  • Cycle time: single command Tsc = 2 max(h/vy, L/vx) + 2Tpd; dual command Tdc = 2 max(1.5h/vy, 1.5L/vx) + 4Tpd (MH-10 approximation).
  • Benefits: higher density, less labour, better inventory control, security.

Automated identification and data capture (AIDC)

  • Bar codes: 1D linear (Code 39, Code 128, UPC/EAN) and 2D (stacked PDF417; matrix QR, Data Matrix). Read by laser/CCD scanners.
  • RFID: tag (chip + antenna) and reader; passive (powered by reader) or active (battery); no line-of-sight needed, read/write, multiple tags at once; frequencies LF/HF/UHF.
  • Others: magnetic stripes, OCR, machine vision, smart cards. AIDC reduces errors versus manual entry (~1 in 300 keystrokes vs ~1 in millions for bar codes).

Computer numerical control (CNC)

  • NC: program of numerical instructions controls a machine tool. CNC: a dedicated computer stores and executes the part program. DNC: several machines served from a central computer.
  • Components: part program, machine control unit (MCU), processing equipment. Axes: Z along spindle, X longest horizontal, Y by right-hand rule; rotary A, B, C about X, Y, Z.
  • Motion control: point-to-point vs contouring (continuous path); interpolation linear (G01) and circular (G02 CW, G03 CCW). G00 rapid positioning; G90 absolute vs G91 incremental; G17/18/19 plane selection; G41/G42 cutter radius compensation; M03 spindle CW; M05 spindle stop; M06 tool change; M08 coolant on; M30 end of program.
  • Control: open loop (stepper) vs closed loop (servo + encoder feedback). Control resolution (open loop with stepper and leadscrew): BLU = p/(ns·rg) (p = screw pitch, ns = steps/rev, rg = gear ratio). Pulse rate fp = v·ns·rg/p.
  • Machining centres with automatic tool changer (ATC), automatic pallet changer. APT language, CAM post-processing.

Single and multi-axis positioning systems

  • Single axis: motor + leadscrew/ball screw (low friction, high efficiency, minimal backlash with preload) or belt/rack-and-pinion/linear motor + guideway + feedback (rotary encoder, linear scale).
  • Multi-axis: stacked XY tables, gantries, CNC axes. Positioning accuracy is affected by resolution, mechanical errors (backlash, pitch error, thermal), and Abbe error.
  • Ball screw: linear speed v = N·p; thrust F = 2πηT/p.

Concurrent design and manufacturing planning

  • Concurrent (simultaneous) engineering: design, manufacturing, quality, purchasing and service work in parallel teams instead of sequentially ("over the wall"). Shorter lead time, fewer changes, lower cost.
  • DFM / DFA (design for manufacture / assembly): minimize part count, use standard parts, design for top-down assembly, self-locating features, avoid flexible parts; Boothroyd–Dewhurst DFA index.
  • Design for automation: parts easy to feed and orient (symmetry or obvious asymmetry), avoid tangling, fewer fasteners.
  • Process planning: manual or computer-aided (CAPP): variant (retrieve similar plan via group technology/coding, e.g. Opitz) or generative (logic creates a new plan).
  • MRP (material requirements planning), MRP II, ERP; capacity planning; master production schedule; shop floor control; JIT/lean; group technology and cellular manufacturing.

Part B1 — Electrical Engineering

B1.1 Analog Circuits and Embedded Systems

Analog filters

  • Low-pass: passes f < fc. First-order RC: H(s) = 1/(1 + sRC), fc = 1/(2πRC); −20 dB/decade roll-off per order; −3 dB and −45° at fc.
  • High-pass: H(s) = sRC/(1 + sRC). Band-pass: passes f₁ < f < f₂; centre f₀ = √(f₁f₂), Q = f₀/BW. Band-reject (notch): rejects a band (e.g. 50 Hz hum; twin-T).
  • Second-order standard form: LP H = ω₀²/(s² + (ω₀/Q)s + ω₀²); −40 dB/decade.
  • Passive (RLC, no gain, loading problems) vs active (op-amp; gain, buffering, no inductors). Sallen–Key and multiple-feedback topologies.
  • Approximations: Butterworth (maximally flat passband), Chebyshev (ripple, sharper roll-off), Bessel (linear phase), Elliptic (sharpest, ripple in both bands). Order n → roll-off 20n dB/decade.

Amplifiers: biasing, equivalent circuit, frequency response

  • BJT: IC = βIB, IE = IC + IB, α = β/(β + 1). Active region: BE forward, BC reverse. VBE ≈ 0.7 V (Si). Thermal voltage VT ≈ 25 mV at room temperature.
  • Biasing: fixed bias (unstable), collector-feedback, voltage-divider bias (most stable; Thevenin: VBB = VCCR₂/(R₁+R₂), IE ≈ (VBB − VBE)/RE when βRE ≫ RB). Stability factor S = ∂IC/∂ICO; Q-point on the DC load line, middle for maximum symmetric swing.
  • Small-signal (hybrid-π): gm = IC/VT; rπ = β/gm; ro = VA/IC. h-parameters: hie ≈ rπ, hfe ≈ β.
  • CE: Av ≈ −gm(RC∥RL), inverting, medium Rin. With unbypassed RE: Av ≈ −RC/RE. CB: non-inverting, low Rin, current gain ≈ 1. CC (emitter follower): Av ≈ 1, high Rin, low Rout (buffer).
  • MOSFET: saturation ID = ½k(VGS − Vt)²; gm = 2ID/(VGS − Vt) = √(2kID). Saturation if VDS ≥ VGS − Vt. CS ≈ CE, CG ≈ CB, CD (source follower) ≈ CC.
  • Frequency response: low-frequency cut-off from coupling/bypass capacitors; high-frequency from junction/parasitic capacitances. Miller effect: Cin = Cμ(1 − Av) — large for high-gain inverting stages. Gain–bandwidth product is roughly constant.
  • Multistage: overall gain = product; overall bandwidth shrinks. Power amplifier classes: A (η ≤ 25%/50%), B (78.5%, crossover distortion), AB, C (tuned).

Feedback amplifiers

  • Closed-loop gain Af = A/(1 + Aβ) (negative feedback). Desensitivity D = 1 + Aβ: gain sensitivity reduced by D, bandwidth increased by D, distortion and noise reduced.
  • Topologies (sampling–mixing): voltage-series (series–shunt): Rin × D, Rout ÷ D — ideal voltage amplifier. Current-series: Rin × D, Rout × D (transconductance). Voltage-shunt: Rin ÷ D, Rout ÷ D (transresistance). Current-shunt: Rin ÷ D, Rout × D (current amplifier). Rule: series mixing raises Rin, shunt lowers; voltage sampling lowers Rout, current sampling raises.

Operational amplifiers

  • Ideal: infinite open-loop gain, Rin = ∞, Rout = 0, infinite bandwidth, CMRR = ∞. With negative feedback: virtual short (V₊ = V₋) and no input current.
  • Non-ideal parameters: input offset voltage/current, bias current, CMRR = Ad/Acm, slew rate (max dVo/dt; full-power bandwidth fmax = SR/(2πVm)), gain–bandwidth product (unity-gain frequency fT: closed-loop BW = fT/ACL), output saturation.

Oscillators

  • Barkhausen criterion: loop gain |Aβ| = 1 and total phase shift = 0° (or 360°). In practice |Aβ| slightly > 1 at start-up.
  • RC phase-shift: three RC sections give 180°; f = 1/(2πRC√6); amplifier gain ≥ 29.
  • Wien bridge: f = 1/(2πRC); β = 1/3 at f₀, so non-inverting gain ≥ 3 (Rf = 2R₁).
  • LC: Colpitts f = 1/(2π√(L Ceq)), Ceq = C₁C₂/(C₁ + C₂). Hartley f = 1/(2π√(LeqC)), Leq = L₁ + L₂ + 2M. Crystal: very stable frequency (high Q), series and parallel resonance.
  • Relaxation oscillators (square/triangular): op-amp astable, T = 2RC ln[(1 + β)/(1 − β)], β = R₂/(R₁ + R₂).

VCOs and timers

  • VCO: output frequency proportional to control voltage (e.g. 566). Used in PLLs (phase detector + loop filter + VCO), FM, frequency synthesis.
  • 555 timer: two comparators (thresholds 2/3 VCC and 1/3 VCC), SR flip-flop, discharge transistor.
  • Monostable: pulse width T = 1.1RC.
  • Astable: tH = 0.693(RA + RB)C; tL = 0.693RBC; f = 1.44/[(RA + 2RB)C]; duty cycle = (RA + RB)/(RA + 2RB) > 50% (add a diode across RB for ≤ 50%).

Schmitt trigger

  • Comparator with positive feedback → two thresholds (hysteresis), giving noise immunity and squaring slow signals.
  • Inverting Schmitt (feedback divider R₁ to ground, R₂ to output): VUT = +VsatR₁/(R₁ + R₂), VLT = −VsatR₁/(R₁ + R₂); hysteresis width VH = VUT − VLT.

Sample-and-hold

  • Switch (MOSFET) + hold capacitor + buffer op-amps. Samples input during sample mode and holds constant during ADC conversion.
  • Specs: acquisition time, aperture time/jitter, droop rate (dV/dt = Ileak/C), feedthrough. Larger C: less droop but slower acquisition.

A/D and D/A converters

  • Resolution: LSB = VFS/2ⁿ (some texts use VFS/(2ⁿ − 1)). Quantization error ±½ LSB; SQNR ≈ 6.02n + 1.76 dB.
  • DAC: weighted-resistor (needs wide resistor range: R, 2R, 4R … 2ⁿ⁻¹R) and R-2R ladder (only two resistor values; Vo = −Vref(Rf/R)·Σbᵢ2ⁱ/2ⁿ). Specs: settling time, monotonicity, linearity (INL/DNL).

Switched-mode power supplies (SMPS)

  • Transistor switched at high frequency with duty cycle D, energy stored in L/C. Efficiency 80–95% (vs linear regulators, η ≈ Vo/Vi). Smaller magnetics at higher frequency; more EMI and ripple.
  • Continuous conduction mode (CCM) steady-state ratios: Buck Vo = D·Vi; Boost Vo = Vi/(1 − D); Buck-boost Vo = −D·Vi/(1 − D) (inverted); Flyback (isolated buck-boost) Vo = Vi(N₂/N₁)·D/(1 − D); forward converter (isolated buck).
  • Derivation: volt-second balance on the inductor (average inductor voltage = 0) and charge balance on the capacitor.
  • Buck ripple: ΔIL = (Vi − Vo)D/(fL); ΔVo = ΔIL/(8fC).

Microprocessors and microcontrollers

  • Microprocessor: CPU only on chip (ALU, registers, control unit); memory and I/O external — general-purpose computing. Microcontroller: CPU + RAM + ROM/Flash + I/O ports + timers + ADC + serial interfaces on one chip — embedded control.
  • Architectures: Von Neumann (shared bus for code and data) vs Harvard (separate; most MCUs). CISC (8085/8051, x86) vs RISC (ARM, AVR, PIC).
  • CPU: ALU, accumulator, general registers, program counter (address of next instruction), stack pointer, instruction register, flags (carry, zero, sign, parity, auxiliary carry, overflow). Fetch–decode–execute cycle; machine cycles and T-states.
  • Memory: ROM/EPROM/EEPROM/Flash (non-volatile program), SRAM (fast, no refresh) and DRAM (refresh). Address lines n → 2ⁿ locations (e.g. 16 lines → 64 KB). Memory map; address decoding with decoders/logic.
  • I/O ports: parallel GPIO with direction registers; 8051 has four 8-bit ports (P0–P3). Serial: UART (asynchronous, start/stop bits, baud rate), SPI (full duplex, master/slave, MOSI/MISO/SCK/SS), I²C (two-wire SDA/SCL, addressed, multi-master), CAN (vehicles/industrial).
  • Timers/counters: count internal clock pulses (timer) or external events (counter). 8051 timer modes 0–3 (13-bit, 16-bit, 8-bit auto-reload, split). Delay = count × machine-cycle time (8051: 12 clock periods per machine cycle). Used for PWM, input capture, baud-rate generation, watchdog.

Interrupt handling

  • Interrupt: external/internal event suspends the main program; CPU finishes the current instruction, pushes PC (and status) onto the stack, jumps to the ISR via the vector table, then returns (RETI/IRET) and restores context.
  • Polling vs interrupts (interrupts give faster response and free the CPU). Maskable vs non-maskable (NMI, e.g. 8085 TRAP). Vectored vs non-vectored. Edge vs level triggering. Priority and nesting.
  • 8085 interrupts priority: TRAP > RST 7.5 > RST 6.5 > RST 5.5 > INTR. 8051: five sources (INT0, TF0, INT1, TF1, serial) with IE and IP registers.
  • Good ISR practice: short, no blocking calls, mark shared variables volatile, disable interrupts around critical sections.

Memory and I/O interfacing

  • Memory-mapped I/O (I/O shares memory address space; all memory instructions usable) vs I/O-mapped / isolated I/O (separate IN/OUT instructions, 8085: 256 ports).
  • Address decoding: full vs partial (partial causes aliasing/foldback). Chip select from address decoder (e.g. 74LS138).
  • Data transfer: programmed I/O, interrupt-driven, DMA (direct memory access; CPU releases buses via HOLD/HLDA for block transfers).
  • Peripheral chips: 8255 PPI, 8253/8254 timer, 8259 interrupt controller, 8251 USART, 8237 DMA controller. Interfacing keypads, 7-segment/LCD displays, ADC/DAC, motors (through drivers, H-bridge, opto-isolation).

Data acquisition systems

  • Chain: sensor → signal conditioning (amplify, filter, isolate) → anti-aliasing low-pass filter → analog multiplexer (multiple channels) → sample-and-hold → ADC → microcontroller/computer → storage/display.
  • Sampling rate ≥ 2 × highest frequency (Nyquist); in practice 5–10×. Aliasing if undersampled. Throughput for N multiplexed channels: per-channel rate = total rate / N.
  • Specs: number of channels, resolution, sampling rate, input range, accuracy, isolation. Single-ended vs differential inputs (differential rejects common-mode noise).

B1.2 Signals and Systems

Signals

  • Continuous-time x(t) and discrete-time x[n]. Periodic: x(t + T) = x(t). Sum of periodic signals is periodic if the ratio of periods is rational; period = LCM. x[n] = cos(ω₀n) is periodic only if ω₀/2π is rational.
  • Even/odd decomposition: xe = ½[x(t) + x(−t)], xo = ½[x(t) − x(−t)].
  • Energy E = ∫|x|²dt (finite ⇒ energy signal, P = 0); power P = lim (1/T)∫|x|²dt (finite non-zero ⇒ power signal, E = ∞).
  • Standard signals: unit step u(t), impulse δ(t) (∫δ = 1, sifting ∫x(t)δ(t − t₀)dt = x(t₀), δ(at) = δ(t)/|a|), ramp r(t) = t u(t), rect, sinc(x) = sin(πx)/(πx), complex exponential est.

Shifting and scaling

  • x(t − t₀): delay (shift right) by t₀. x(at): compress if |a| > 1, expand if |a| < 1. x(−t): time reversal.
  • For y(t) = x(at − b): shift first by b, then scale by a (i.e. x(a(t − b/a))). Check with key points.
  • Discrete: x[2n] (decimation) loses samples; x[n/2] (interpolation) defined only for even n.

System properties

  • Linear: additivity + homogeneity (superposition). y = ax + b with b ≠ 0 is not linear (incrementally linear).
  • Time-invariant: a delayed input gives the same delayed output. y(t) = x(2t) or y(t) = t x(t) are time-variant.
  • Causal: output depends only on present and past inputs; LTI causal ⇔ h(t) = 0 for t < 0.
  • Memoryless (static): output depends only on the present input; LTI ⇔ h(t) = kδ(t).
  • BIBO stable: bounded input → bounded output; LTI ⇔ ∫|h(t)|dt < ∞ (Σ|h[n]| < ∞).
  • Invertible: distinct inputs → distinct outputs.
  • LTI output: convolution y(t) = x(t) * h(t) = ∫x(τ)h(t − τ)dτ; y[n] = Σx[k]h[n − k]. Commutative, associative, distributive. Cascade: h₁ * h₂; parallel: h₁ + h₂. Length of discrete linear convolution = N + M − 1. Eigenfunction: est → H(s)est.

Fourier series

  • CT periodic: x(t) = Σ ck ejkω₀t, ck = (1/T)∫T x(t) e−jkω₀tdt. Real x ⇒ c₋ₖ = ck*. Trigonometric form: a₀ + Σ(akcos + bksin).
  • Symmetry: even → cosine terms only; odd → sine terms only; half-wave symmetry x(t ± T/2) = −x(t) → odd harmonics only.
  • Parseval: P = Σ|ck|². Square wave has odd harmonics decaying as 1/k; triangle wave as 1/k². Gibbs phenomenon: ~9% overshoot at discontinuities.
  • DT Fourier series: x[n] periodic with N; coefficients are also periodic with N (only N distinct).

Sampling theorem (Shannon)

  • A band-limited signal with maximum frequency fm can be perfectly recovered from samples if fs ≥ 2fm (Nyquist rate = 2fm; Nyquist interval = 1/2fm). Reconstruct with an ideal low-pass filter (sinc interpolation), cut-off between fm and fs − fm.
  • Sampled spectrum: copies of X(f) repeated every fs. If fs < 2fm → aliasing: a tone at f appears at |f − k fs| folded into [0, fs/2].
  • For a product of signals, bandwidths add; for x²(t), bandwidth doubles. Band-pass sampling: fs = 2fH/k.

Fourier transform

  • X(ω) = ∫x(t)e−jωtdt; x(t) = (1/2π)∫X(ω)ejωtdω.
  • Properties: linearity; time shift x(t − t₀) ↔ e−jωt₀X; frequency shift ejω₀tx ↔ X(ω − ω₀); scaling x(at) ↔ (1/|a|)X(ω/a); duality; differentiation ↔ jωX; integration ↔ X/jω + πX(0)δ(ω); convolution ↔ product; product ↔ (1/2π) convolution; modulation x cos ω₀t ↔ ½[X(ω − ω₀) + X(ω + ω₀)]; Parseval ∫|x|²dt = (1/2π)∫|X|²dω.
  • Real and even x ⇒ X real and even; real and odd ⇒ X imaginary and odd. X(0) = ∫x dt; x(0) = (1/2π)∫X dω.
  • Pairs: δ ↔ 1; 1 ↔ 2πδ(ω); e−atu(t) ↔ 1/(a + jω); rect(t/T) ↔ T sinc(ωT/2π); sinc ↔ rect; e−a|t| ↔ 2a/(a² + ω²); Gaussian ↔ Gaussian; u(t) ↔ πδ(ω) + 1/jω; sgn ↔ 2/jω.
  • DTFT X(ejω) = Σx[n]e−jωn is periodic in ω with period 2π. DFT: N-point sampled DTFT; FFT computes it in O(N log N).

Laplace transform

  • X(s) = ∫x(t)e−stdt with region of convergence (ROC). Right-sided signals: ROC to the right of the rightmost pole; left-sided: left of the leftmost pole; two-sided: strip.
  • LTI system H(s): causal ⇒ ROC is a right half-plane; stable ⇒ ROC includes the jω-axis; causal and stable ⇒ all poles in the LHP.
  • Fourier transform = Laplace on s = jω (if ROC includes jω-axis). Properties as in the mathematics section (shift, derivative, convolution, initial/final value theorems).

Z-transform

  • X(z) = Σx[n]z−n. Pairs: δ[n] ↔ 1; u[n] ↔ z/(z − 1), |z| > 1; aⁿu[n] ↔ z/(z − a), |z| > |a|; −aⁿu[−n − 1] ↔ z/(z − a), |z| < |a|; n aⁿu[n] ↔ az/(z − a)².
  • Properties: shift x[n − k] ↔ z−kX; aⁿx ↔ X(z/a); n x ↔ −z dX/dz; convolution ↔ product; initial value x[0] = limz→∞X; final value x[∞] = limz→1(z − 1)X.
  • ROC: no poles inside; causal ⇒ outside the outermost pole; stable ⇒ contains the unit circle; causal and stable ⇒ all poles inside the unit circle. DTFT = X(z) on |z| = 1. s-plane to z-plane: z = esT.
  • Difference equation y[n] − a y[n − 1] = x[n] → H(z) = 1/(1 − az⁻¹). FIR (no feedback, always stable, can be linear phase) vs IIR (feedback poles).

B1.3 Control Systems

Modelling and representation

  • Mechanical translational: F = M ẍ + B ẋ + K x. Rotational: T = J θ̈ + B θ̇ + K θ. Electrical RLC.
  • Analogies: force–voltage (M ↔ L, B ↔ R, K ↔ 1/C, x ↔ q) and force–current (M ↔ C, B ↔ 1/R, K ↔ 1/L).
  • Gear trains: θ₁/θ₂ = N₂/N₁; T₂/T₁ = N₂/N₁; load inertia reflected to the motor side: Jeq = Jm + JL(N₁/N₂)².
  • State space: ẋ = Ax + Bu, y = Cx + Du; G(s) = C(sI − A)⁻¹B + D. Eigenvalues of A = poles. State transition matrix Φ(t) = eAt = L⁻¹{(sI − A)⁻¹}. Controllability: rank[B AB … Aⁿ⁻¹B] = n; observability: rank[C; CA; …; CAⁿ⁻¹] = n.

Feedback principle and transfer function

  • Transfer function = L{output}/L{input} with zero initial conditions; = Laplace transform of the impulse response. Poles: roots of denominator; zeros: roots of numerator. Order = highest power of s in the denominator.
  • Closed loop (negative feedback): T(s) = G/(1 + GH). Characteristic equation: 1 + G(s)H(s) = 0.
  • Feedback reduces sensitivity to parameter changes (STG = 1/(1 + GH)), rejects disturbances, can improve speed and stabilize, but can also destabilize and adds cost/complexity; it reduces overall gain.
  • Open-loop: simple, no stability issue, but cannot correct disturbances.

Block diagrams and signal flow graphs

  • Series: G₁G₂. Parallel: G₁ ± G₂. Feedback loop: G/(1 ± GH). Moving a summing point ahead of a block: divide by G; behind: multiply by G. Moving a take-off point ahead: multiply by G; behind: divide by G.
  • Mason's gain formula: T = (1/Δ)ΣPkΔk. Δ = 1 − (sum of individual loop gains) + (sum of products of two non-touching loops) − (three non-touching) + … Δk = Δ with the loops touching the k-th forward path removed.

Transient response

  • First order G = K/(τs + 1): step response K(1 − e−t/τ); 63.2% at t = τ; settling time ≈ 4τ (2%); rise time (10–90%) = 2.2τ.
  • Second order: G = ωₙ²/(s² + 2ζωₙs + ωₙ²); poles −ζωₙ ± jωₙ√(1 − ζ²). ζ = 0 undamped, 0 < ζ < 1 underdamped, 1 critical, > 1 overdamped.
  • Underdamped step specs: damped frequency ωd = ωₙ√(1 − ζ²); peak time tp = π/ωd; percent overshoot Mp = e−πζ/√(1−ζ²) × 100%; settling time ts = 4/(ζωₙ) (2%) or 3/(ζωₙ) (5%); rise time tr = (π − θ)/ωd, θ = cos⁻¹ζ. Number of oscillations ≈ ts/(2π/ωd).
  • Dominant poles: poles closest to the jω-axis dominate; poles > 5× further left can be neglected.

Steady-state error

  • Unity feedback: ess = lims→0 sR(s)/(1 + G(s)). Type = number of poles of G(s)H(s) at the origin.
  • Error constants: Kp = lim G(s); Kv = lim sG(s); Ka = lim s²G(s) (as s → 0).

Routh–Hurwitz criterion

  • Necessary: all coefficients of the characteristic polynomial present and of the same sign.
  • Build the Routh array; number of sign changes in the first column = number of roots in the RHP. Stable iff no sign changes.
  • Special cases: zero in first column (replace with ε → 0⁺); entire row zero (auxiliary polynomial A(s) from the row above, use dA/ds; indicates symmetric roots, e.g. on the jω-axis → marginal stability; roots of A(s) give the oscillation frequency).
  • Second order: stable iff all coefficients > 0. Third order a₀s³ + a₁s² + a₂s + a₃: stable iff all > 0 and a₁a₂ > a₀a₃. Use to find K range for stability and Kmarginal.

Nyquist criterion

  • Plot G(jω)H(jω) for ω from −∞ to ∞ (go around RHP poles/zeros on the jω-axis with small semicircles).
  • Z = P − N (N = counter-clockwise encirclements of −1 + j0; P = open-loop RHP poles; Z = closed-loop RHP poles). Stable iff Z = 0, i.e. N = P. (With clockwise counting: Z = P + N.)
  • Open-loop stable (P = 0) ⇒ stable iff no encirclement of −1.
  • Gain margin GM = 1/|GH(jωpc)| at the phase-crossover frequency (phase = −180°); in dB: −20 log|GH(jωpc)|. Phase margin PM = 180° + ∠GH(jωgc) at the gain-crossover frequency (|GH| = 1). Stable (minimum-phase) when both positive. PM ≈ 100ζ for ζ < 0.7.

Bode plots

  • Magnitude in dB (20 log|G|) and phase versus log ω.
  • Gain K: flat 20 log K, 0° (180° if negative). Pole at origin 1/s: −20 dB/dec through 0 dB at ω = 1, −90°. Zero at origin: +20 dB/dec, +90°.
  • Simple pole 1/(1 + s/a): 0 dB until ω = a then −20 dB/dec (actual −3 dB at the corner); phase 0 → −90° (−45° at a). Simple zero: +20 dB/dec, 0 → +90°.
  • Quadratic pole: −40 dB/dec after ωₙ, phase 0 → −180°; resonant peak Mr = 1/(2ζ√(1 − ζ²)) at ωr = ωₙ√(1 − 2ζ²) (for ζ < 0.707).
  • Initial slope reveals the system type (−20 × type dB/dec). Final slope = −20 × (poles − zeros). Non-minimum phase (RHP zero) shows extra phase lag for the same magnitude. Transport delay e−sT: magnitude 1, phase −ωT.
  • Bandwidth of a second-order system: ωb = ωₙ√[(1 − 2ζ²) + √(4ζ⁴ − 4ζ² + 2)].

Root locus

  • Locus of closed-loop poles as K varies 0 → ∞, from 1 + KG(s)H(s) = 0. Angle condition: ∠GH = ±180°(2q + 1); magnitude condition: |KGH| = 1 (gives K at a point).
  • Rules: starts at open-loop poles (K = 0), ends at zeros (K = ∞) or infinity. Number of branches = number of poles. Symmetric about the real axis. Real-axis segment is on the locus if an odd number of poles + zeros lie to its right.
  • Asymptotes: n − m of them, angles (2q + 1)180°/(n − m); centroid σ = (Σpoles − Σzeros)/(n − m).
  • Break-away/break-in points: dK/ds = 0. jω-axis crossings: Routh array. Angle of departure from a complex pole: 180° − Σ(angles from other poles) + Σ(angles from zeros); arrival at a complex zero analogously.
  • Adding a pole pushes the locus right (less stable); adding a zero pulls it left (more stable).

Compensators

  • Lead Gc = (1 + aTs)/(1 + Ts), a > 1 (zero closer to origin than the pole). Adds phase lead: φmax = sin⁻¹[(a − 1)/(a + 1)] at ωm = 1/(T√a). Improves PM, transient response and bandwidth (high-pass, amplifies noise). Approximates PD.
  • Lag Gc = (1 + aTs)/(1 + Ts), a < 1 (pole closer to origin). Increases low-frequency gain → reduces steady-state error; place well below crossover to avoid phase loss; reduces bandwidth (slower). Approximates PI.
  • Lead–lag: combines both — lead for transient response, lag for steady-state accuracy.

P, PI, PID controllers

  • u(t) = Kpe + Ki∫e dt + Kd de/dt; Gc(s) = Kp + Ki/s + Kds.
  • P: faster response, reduces but does not eliminate steady-state error; high gain → overshoot/instability.
  • I (PI): adds a pole at the origin → raises system type by 1 → eliminates steady-state error to a step; can increase overshoot and reduce stability; integral wind-up (use anti-windup).
  • D (PD): adds a zero → anticipates error, adds damping, reduces overshoot and settling time, improves stability; amplifies noise (use a filtered derivative); no effect on steady-state error.
  • PID: combines all three. Ziegler–Nichols (ultimate-gain method): Kp = 0.6Ku, Ti = Pu/2, Td = Pu/8; P only: 0.5Ku; PI: 0.45Ku, Ti = Pu/1.2.

Part B2 — Mechanical Engineering

B2.1 Mechanics of Materials

Stress and strain

  • Normal stress σ = P/A; shear stress τ = V/A. Normal strain ε = δL/L; shear strain γ (radians).
  • Hooke's law: σ = Eε; τ = Gγ. Axial deformation δ = PL/(AE); for stepped bars sum each segment; bar under own weight δ = ρgL²/(2E) = WL/(2AE).
  • Stress–strain curve (mild steel): proportional limit, elastic limit, upper/lower yield points, ultimate strength, fracture. Ductile (large plastic strain, cup-and-cone fracture) vs brittle (cast iron, little plastic strain).
  • Factor of safety = failure stress/allowable stress. Strain energy U = σ²V/(2E) = P²L/(2AE). Modulus of resilience σy²/(2E). Toughness = area under the curve.
  • Suddenly applied load: stress = 2× gradually applied. Impact load from height h: σ = (P/A)[1 + √(1 + 2AEh/(PL))].
  • Composite bars in parallel: same strain, load shared in proportion to AE.

Elastic constants and Poisson's ratio

  • Poisson's ratio ν = −εlateral/εaxial; 0 ≤ ν ≤ 0.5 (0.5 incompressible, rubber; ~0.3 steel; ~0 cork).
  • E = 2G(1 + ν) = 3K(1 − 2ν); E = 9KG/(3K + G).
  • Volumetric strain εv = εx + εy + εz; for uniaxial: ε(1 − 2ν). Bulk modulus K = −p/εv.
  • Generalized Hooke: εx = [σx − ν(σy + σz)]/E.

Mohr's circle — plane stress

  • Stresses on a plane at θ: σθ = (σx + σy)/2 + [(σx − σy)/2]cos 2θ + τxysin 2θ; τθ = −[(σx − σy)/2]sin 2θ + τxycos 2θ.
  • Principal stresses σ₁,₂ = (σx + σy)/2 ± √{[(σx − σy)/2]² + τxy²}; principal planes tan 2θp = 2τxy/(σx − σy); zero shear on principal planes.
  • Max in-plane shear τmax = (σ₁ − σ₂)/2 = radius of Mohr's circle, on planes at 45° to principal planes (normal stress = average there). Absolute max shear (3D) = (σmax − σmin)/2 including σ₃ = 0.
  • Mohr's circle: centre ((σx + σy)/2, 0), radius R as above; an angle θ on the element = 2θ on the circle. σx + σy is invariant.
  • Pure shear: σ₁ = τ, σ₂ = −τ at 45°. Uniaxial σ: τmax = σ/2 at 45°.

Plane strain

  • Same transformation with σ → ε and τ → γ/2. Principal strains ε₁,₂ = (εx + εy)/2 ± √{[(εx − εy)/2]² + (γxy/2)²}. Max shear strain γmax = ε₁ − ε₂.

Thin cylinders and spheres (t < d/20)

  • Hoop (circumferential) σh = pd/(2t); longitudinal σl = pd/(4t) = σh/2. Max in-plane shear = pd/(8t); absolute max = pd/(4t).
  • Thin sphere: σ = pd/(4t) in all directions.
  • Volumetric strain of cylinder: (pd/4tE)(5 − 4ν); sphere: (3pd/4tE)(1 − ν). Joint efficiency η: σh = pd/(2tηl), σl = pd/(4tηc).
  • Thick cylinders (Lamé): σr = A − B/r², σh = A + B/r²; max hoop stress at inner radius.

Shear force and bending moment diagrams

  • Relations: dV/dx = −w (load intensity; sign conventions vary), dM/dx = V. Max bending moment where SF = 0 (or changes sign). Point load → step in SFD; UDL → linear SFD and parabolic BMD; uniformly varying load → parabolic SFD and cubic BMD. Applied couple → jump in BMD.
  • Point of contraflexure: BM changes sign (only in overhanging/fixed beams).
  • Standard maxima: simply supported, central load P: Mmax = PL/4; UDL w: wL²/8. Cantilever end load P: PL; UDL: wL²/2. Fixed–fixed UDL: wL²/12 at supports, wL²/24 at centre.

Bending and shear stresses in beams

  • Flexure formula: M/I = σ/y = E/R; σmax = M/Z, section modulus Z = I/ymax. Neutral axis passes through the centroid (zero bending stress).
  • I values: rectangle bh³/12 (Z = bh²/6); circle πd⁴/64 (Z = πd³/32); hollow circle π(D⁴ − d⁴)/64; triangle about base bh³/12, about centroid bh³/36.
  • Shear stress τ = VQ/(Ib) (Q = first moment of area above the point). Rectangle: τmax = 1.5τavg at neutral axis (parabolic distribution). Circle: τmax = (4/3)τavg. I-section: web carries most shear.
  • Beam of uniform strength: section varies so that M/Z is constant.

Shear centre

  • Point through which a transverse load must act to cause bending without twisting. Coincides with the centroid for doubly symmetric sections; lies on the axis of symmetry for singly symmetric sections.
  • Channel section: shear centre lies outside the web, at e = b²h²t/(4I) from the web centre line (b = flange width, h = web height between flange centres, t = flange thickness). Angle and T sections: at the intersection of the legs/flange-web centre lines.

Torsion of circular shafts

  • T/J = τ/r = Gθ/L. Polar moment J = πd⁴/32 (solid), π(D⁴ − d⁴)/32 (hollow). τmax = 16T/(πd³) (solid).
  • Angle of twist θ = TL/(GJ); torsional stiffness GJ/L. Power P = 2πNT/60 (N in rpm).
  • Series shafts: same torque, angles add. Parallel (both ends fixed, torque at a point): same angle, torques add.
  • Hollow shafts are stronger and stiffer per unit weight. Combined bending and torsion: equivalent torque Te = √(M² + T²); equivalent moment Me = ½[M + √(M² + T²)].
  • Closely coiled helical spring: τ = 8WDK/(πd³) (K = Wahl factor); deflection δ = 8WD³n/(Gd⁴); stiffness k = Gd⁴/(8D³n). Springs in series: 1/k = Σ1/kᵢ; parallel: k = Σkᵢ.

Euler's theory of columns

  • Critical buckling load Pcr = π²EImin/Le².
  • Effective length Le: both ends pinned L; one fixed one free 2L; both fixed L/2; one fixed one pinned L/√2.
  • Slenderness ratio λ = Le/k (k = √(I/A), radius of gyration); critical stress σcr = π²E/λ². Euler valid for long columns (λ above the limit where σcr = σyield; ≈ 80–100 for mild steel).
  • Rankine–Gordon (short and intermediate columns): 1/PR = 1/Pcrushing + 1/PEuler.
  • Eccentric loading: secant formula. Buckling occurs about the axis of minimum I.

Castigliano's theorems (energy methods)

  • Strain energy: axial ∫N²dx/(2AE); bending ∫M²dx/(2EI); torsion ∫T²dx/(2GJ); shear ∫kV²dx/(2GA).
  • Castigliano's (second) theorem: deflection at the point of load Pᵢ in its direction δᵢ = ∂U/∂Pᵢ; rotation θ = ∂U/∂M. (First theorem: Pᵢ = ∂U/∂δᵢ.) To find deflection where no load acts, apply a dummy load Q and set Q = 0 after differentiating.
  • Statically indeterminate structures: ∂U/∂R = 0 for a redundant reaction R (theorem of least work).
  • Maxwell's reciprocal theorem: δij = δji.

Thermal stresses

  • Free thermal strain εT = αΔT; free expansion δ = αLΔT (no stress).
  • Fully restrained: σ = EαΔT (compressive when heated). Partially restrained with gap δ₀: σ = E(αLΔT − δ₀)/L.
  • Composite bars of different materials heated together: compatibility of strain; the one with higher α goes into compression. σ₁A₁ = σ₂A₂ (equilibrium); α₁ΔT − σ₁/E₁ = α₂ΔT + σ₂/E₂.

Strain gauges and rosettes

  • Strain gauge: GF = (ΔR/R)/ε. Measures normal strain in one direction only; shear strain must be derived.
  • Rosette (three gauges at known angles) gives εx, εy, γxy using εθ = εxcos²θ + εysin²θ + γxysin θ cos θ.
  • Rectangular (0°, 45°, 90°): εx = ε₀, εy = ε₉₀, γxy = 2ε₄₅ − ε₀ − ε₉₀. Delta (0°, 60°, 120°) rosettes also used.
  • Principal stresses from principal strains: σ₁ = E(ε₁ + νε₂)/(1 − ν²); σ₂ = E(ε₂ + νε₁)/(1 − ν²).

Testing of materials

  • Universal testing machine (UTM): tension, compression, bending, shear tests. Results: E, yield strength (0.2% offset proof stress for materials without a clear yield point), UTS, % elongation = (Lf − L₀)/L₀ × 100, % reduction in area (ductility). Engineering vs true stress (σtrue = σ(1 + ε), εtrue = ln(1 + ε)). Necking starts at UTS.
  • Hardness: Brinell (hardened steel/tungsten ball, BHN = 2P/[πD(D − √(D² − d²))], soft-to-medium metals); Vickers (diamond pyramid 136°, HV = 1.854P/d², all hardness ranges, micro-hardness); Rockwell (depth of penetration, minor + major load; scales B (ball, soft) and C (diamond cone, hard)); Knoop (thin layers); Shore scleroscope (rebound) and Mohs (scratch). UTS ≈ 3.45 × BHN (MPa) for steels.
  • Impact strength: Charpy (simply supported, notch facing away from striker) and Izod (cantilever, notch facing striker). Energy absorbed = W(h₁ − h₂). Ductile-to-brittle transition temperature (BCC metals).
  • Others: fatigue (rotating beam), creep, torsion test, non-destructive testing (ultrasonic, radiography, dye penetrant, magnetic particle, eddy current).

B2.2 Kinematics and Dynamics of Machines

Mechanisms basics

  • Kinematic link, pair (lower: surface contact; higher: point/line contact), chain, mechanism (one link fixed), machine. Inversion: fixing different links of the same chain.
  • Mobility (Grübler, planar): F = 3(n − 1) − 2j − h (j = lower pairs, h = higher pairs). F = 0 structure; F < 0 indeterminate; F = 1 constrained mechanism.
  • Grashof's law (four-bar): s + l ≤ p + q ⇒ at least one link can fully rotate. Shortest link as crank → crank-rocker; shortest as frame → double crank (drag link); shortest as coupler → double rocker. Non-Grashof → triple rocker.
  • Inversions: four-bar (beam engine, coupling rod of locomotive, Watt's indicator); single slider-crank (reciprocating engine, Whitworth quick return, rotary engine, oscillating cylinder, hand pump); double slider-crank (elliptical trammel, Scotch yoke, Oldham coupling).
  • Quick-return ratio = time of cutting / time of return = α/β (crank angles). Transmission angle μ (best near 90°, acceptable 40°–140°). Toggle position: mechanical advantage → ∞.

Displacement, velocity and acceleration analysis

  • Relative velocity: vBA = ω·AB, perpendicular to AB. Velocity polygons drawn link by link.
  • Instantaneous centres: number of ICs N = n(n − 1)/2. Kennedy's theorem: the three ICs of three bodies in plane motion lie on a straight line. Velocity v = ω × distance from IC. Slider on a fixed straight path: IC at infinity perpendicular to the path.
  • Acceleration: centripetal (radial) ar = ω²r = v²/r towards the centre; tangential at = αr. Coriolis component 2ωv (when a point slides along a rotating link; direction: rotate the sliding velocity by 90° in the sense of ω) — appears in quick-return and slotted-link mechanisms.
  • Slider-crank (crank r, connecting rod l, n = l/r): piston displacement x ≈ r[(1 − cos θ) + (sin²θ)/(2n)]; velocity v ≈ ωr(sin θ + sin 2θ/(2n)); acceleration a ≈ ω²r(cos θ + cos 2θ/n). Angular velocity of connecting rod ωc ≈ ω cos θ/n.
  • Analytical: loop-closure equations; graphical: polygons; Klein's construction for slider-crank.

Dynamic analysis of linkages

  • D'Alembert: add inertia force −m aG and inertia couple −IGα; then solve as a static problem (link by link, or by virtual work: Σ(F·v) + Σ(T·ω) = 0).
  • Slider-crank engine: piston effort FP = gas force − inertia force (FI = mRω²r(cos θ + cos 2θ/n)); force along connecting rod FQ = FP/cos φ; crank effort/torque T = FP·r·sin(θ + φ)/cos φ ≈ FPr(sin θ + sin 2θ/(2√(n² − sin²θ))).
  • Dynamically equivalent two-mass system: same total mass, same centroid, same moment of inertia (l₁l₂ = k²).
  • Turning moment diagram and flywheel: fluctuation of energy ΔE = Iω²Cs = mk²ω²Cs; coefficient of fluctuation of speed Cs = (ωmax − ωmin)/ωmean. Rim flywheel: ΔE = mv²Cs.
  • Governors (Watt, Porter, Proell, Hartnell): control mean speed with load; sensitiveness, stability, isochronism, hunting. Flywheel controls cyclic fluctuations within a cycle.

Gears and gear trains

  • Law of gearing: the common normal at the point of contact passes through a fixed point (pitch point) → constant velocity ratio. Satisfied by involute and cycloidal profiles. Involute: centre-distance changes do not affect the velocity ratio; pressure angle constant (14.5°, 20°).
  • Terminology: module m = d/T (mm); circular pitch p = πm; diametral pitch P = T/d; addendum = 1m (standard), dedendum = 1.25m; base circle db = d cos φ. Velocity ratio ω₁/ω₂ = T₂/T₁ = d₂/d₁.
  • Path of contact = √(Ra² − R²cos²φ) + √(ra² − r²cos²φ) − (R + r)sin φ. Arc of contact = path/cos φ. Contact ratio = arc of contact/circular pitch (> 1, usually 1.2–1.6).
  • Interference: tip of one gear digs into the non-involute flank of the other. Minimum teeth on pinion to avoid interference (rack, 20° full depth): Tmin = 2aw/sin²φ ≈ 17 (32 for 14.5°). Remedies: increase pressure angle, stub teeth, undercutting, profile shift.
  • Gear types: spur, helical (axial thrust; double helical/herringbone cancels it), bevel (intersecting shafts), worm and wheel (large ratio, non-intersecting perpendicular shafts, often self-locking), rack and pinion, hypoid, spiral.
  • Gear trains: simple (idler only changes direction), compound (speed ratio = product of driven teeth/product of driver teeth), reverted (input and output coaxial).
  • Epicyclic (planetary) trains: arm rotates; use the tabular method (lock arm, give +1 rotation to sun, then add arm rotation) or the relative velocity formula (Ns − Na)/(Nr − Na) = −Tr/Ts. Ring teeth Tr = Ts + 2Tp (same module). Torque balance: ΣT = 0 (Tin + Tout + Tfixed = 0) and power balance ΣTω = 0. Used in automatic transmissions, differentials, robot reducers.
  • Harmonic drives (strain wave): very high ratio, zero backlash — common in robot joints.

Balancing of rotating masses

  • Unbalanced force from mass m at radius r: F = mω²r.
  • Static balance: Σmr = 0 (vector sum; one balancing mass in the same plane). Dynamic balance: Σmr = 0 and Σmrl = 0 (couple about a reference plane); requires two balancing masses in two planes.
  • Graphical: force polygon and couple polygon (reference plane chosen at one balancing plane to eliminate its unknown).

Balancing of reciprocating masses

  • Primary disturbing force m ω²r cos θ; secondary m ω²r cos 2θ/n (behaves like a mass at radius r/(4n) rotating at 2ω).
  • Single cylinder: primary force can be only partially balanced (fraction c of the reciprocating mass); adding rotating balance mass introduces an unbalanced vertical force c mω²r sin θ. Typically c = 2/3 to 3/4 in locomotives (hammer blow, swaying couple, variation of tractive effort).
  • Multi-cylinder in-line: Σ primary forces and couples = 0, Σ secondary forces and couples = 0 (use direct and reverse crank method for V-engines and radial engines). In-line 6-cylinder engines are fully balanced for primary and secondary.

Gyroscope

  • Gyroscopic couple C = Iωωp (I = spin moment of inertia, ω = spin, ωp = precession). The spin vector moves towards the applied torque vector (precession).
  • Ship: steering (turning) → pitching effect on bow/stern; pitching → yawing (steering) effect; rolling → no gyroscopic effect (spin and roll axes parallel). Aeroplane turning → nose up or down depending on directions.
  • Vehicles on curved track: gyroscopic couple of wheels and engine changes wheel reactions, adds to overturning effect. Two-wheeler cornering requires leaning.
  • Gyroscopes in navigation/stabilization (and MEMS gyros in robot IMUs).

Vibrations of single DOF systems

  • Free undamped: m ẍ + kx = 0; ωₙ = √(k/m); fₙ = ωₙ/2π; static deflection δst = mg/k → ωₙ = √(g/δst). Energy method (Rayleigh): d(KE + PE)/dt = 0.
  • Examples: simple pendulum ωₙ = √(g/L); compound pendulum ωₙ = √(mgh/IO); torsional ωₙ = √(kt/I); spring mass with spring mass ms: add ms/3. Cantilever end mass k = 3EI/L³; simply supported centre k = 48EI/L³.
  • Free damped: m ẍ + c ẋ + kx = 0. Critical damping cc = 2√(km) = 2mωₙ; damping ratio ζ = c/cc. ζ < 1 underdamped: ωd = ωₙ√(1 − ζ²). Logarithmic decrement δ = ln(xn/xn+1) = 2πζ/√(1 − ζ²) ≈ 2πζ; over n cycles δ = (1/n)ln(x₀/xn).
  • Coulomb (dry friction) damping: amplitude decreases linearly by 4F/k per cycle.
  • Forced vibration F₀ sin ωt: steady-state amplitude X = (F₀/k)/√[(1 − r²)² + (2ζr)²], r = ω/ωₙ. Magnification factor MF = X/(F₀/k). Phase tan φ = 2ζr/(1 − r²) (90° at resonance).
  • Peak amplitude at r = √(1 − 2ζ²); at resonance (r = 1) MF = 1/(2ζ). For r ≫ 1 the mass barely moves (X → F₀/(mω²)).
  • Rotating unbalance m₀e: X = (m₀e/m)·r²/√[(1 − r²)² + (2ζr)²]. Base excitation: same as transmissibility below.

Effect of damping; vibration isolation

  • Damping reduces amplitude near resonance strongly, has little effect far from resonance.
  • Transmissibility TR = FT/F₀ = √[1 + (2ζr)²]/√[(1 − r²)² + (2ζr)²].
  • TR = 1 at r = √2 for any ζ. Isolation (TR < 1) only when r > √2 → use soft mounts (low k, low ωₙ). In the isolation region, more damping increases TR (worse), but damping helps when passing through resonance during start-up.
  • Isolation efficiency = 1 − TR.

Resonance and critical speed of shafts

  • Resonance: forcing frequency = natural frequency → large amplitudes, limited only by damping.
  • Critical (whirling) speed: rotor speed at which the shaft whirls violently = its natural transverse frequency, ωc = √(k/m) = √(g/δst); Nc = (60/2π)√(g/δ). Shaft with eccentricity e: whirl amplitude y = e r²/(1 − r²) (undamped); above critical speed the shaft centre tends towards the mass centre (self-centring).
  • Multiple loads — Dunkerley: 1/ωc² = 1/ω₁² + 1/ω₂² + … + 1/ωs² (lower bound). Rayleigh's method for the fundamental frequency (upper bound).
  • Two-rotor torsional system: node location from IAlA = IBlB; ω = √(GJ/(IAlA)).

B2.3 Machine Design and Computer Integrated Manufacturing

Design for static loading

  • Allowable stress = σy/FoS (ductile) or σu/FoS (brittle). Factor of safety accounts for uncertainty in load, material, analysis.
  • Stress concentration Kt = σmax/σnom (holes, notches, fillets, keyways). Elliptical hole in a plate: Kt = 1 + 2a/b; circular hole: 3. Important for brittle materials under static load and for all materials under fatigue; reduce with generous fillets, relief grooves.
  • Combined loads: superpose normal stresses; compute principal stresses; apply a failure theory.

Fatigue strength and the S-N diagram

  • Fatigue: failure under fluctuating stress well below Su; crack initiation at stress raisers, propagation (beach marks), sudden final fracture.
  • S-N (Wöhler) diagram: log stress amplitude vs log cycles. Steels show an endurance limit Se′ ≈ 0.5Sut (for Sut ≤ 1400 MPa) at ~10⁶–10⁷ cycles; non-ferrous metals (aluminium) have no endurance limit. Low-cycle (<10³) vs high-cycle fatigue; 10³ cycles ≈ 0.9Sut.
  • Corrected endurance limit (Marin): Se = kakbkckdkeSe′ (surface, size, load, temperature, reliability factors). Fatigue stress concentration Kf = 1 + q(Kt − 1), notch sensitivity 0 ≤ q ≤ 1.
  • Fluctuating stress: mean σm = (σmax + σmin)/2; amplitude σa = (σmax − σmin)/2; stress ratio R = σmin/σmax (fully reversed R = −1).
  • Mean-stress criteria: Soderberg σa/Se + σm/Sy = 1/N (most conservative); Goodman σa/Se + σm/Sut = 1/N; Gerber parabola Nσa/Se + (Nσm/Sut)² = 1.
  • Cumulative damage — Miner's rule: Σnᵢ/Nᵢ = 1 at failure.
  • Improve fatigue life: polish surfaces, shot peening (compressive residual stress), avoid sharp corners, nitriding/case hardening.

Bolted joints

  • Tensile stress area; σ = P/At. Core diameter dc ≈ 0.84d. Shear of bolts in single/double shear: P = n·(π/4)d²·τ (×2 for double).
  • Preload (initial tension) Fi; external load P shared: bolt load Fb = Fi + C·P, C = kb/(kb + km) (joint stiffness constant); joint separates when (1 − C)P = Fi. Tightening torque T ≈ 0.2Fid.
  • Eccentrically loaded bolted joints: primary (direct) shear P/n on each bolt + secondary shear from moment ∝ distance from the centroid of the bolt group: F″ᵢ = P·e·rᵢ/Σr²; combine vectorially. For a moment in the plane perpendicular to bolts (bracket), tensile load ∝ distance from the tilting edge: Fᵢ = P·e·lᵢ/Σl².
  • Power screws: torque to raise T = W(dm/2)tan(φ + α) (square thread); self-locking if φ > α; efficiency η = tan α/tan(α + φ) < 50% if self-locking.

Riveted joints

  • Lap and butt joints (single/double strap). Failure modes per pitch length: tearing of plate Pt = (p − d)tσt; shearing of rivets Ps = n(π/4)d²τ (×2 for double shear; IBR: ×1.875); crushing Pc = n·d·t·σc.
  • Efficiency η = min(Pt, Ps, Pc)/(p·t·σt). Unwin's formula d = 6√t (mm). Caulking and fullering for leak-proof boiler joints.

Welded joints

  • Butt weld: P = σt·t·l. Fillet weld throat t = 0.707s (leg size s). Transverse fillet: P = 0.707s·l·σt; parallel (longitudinal) fillet: P = 0.707s·l·τ (failure in shear along the throat).
  • Eccentric loading: primary shear P/A plus secondary shear τ₂ = M·r/J (J = polar moment of the weld throat area, using unit-weld properties Ju × 0.707s); combine vectorially. Bending: σb = M/Z of the weld.
  • Stress concentration factors for welds in fatigue (reinforced butt weld 1.2, toe of transverse fillet 1.5, end of parallel fillet 2.7).

Shafts, keys and couplings

  • Shaft design by strength: ASME code d³ = (16/πτallow)√[(KbM)² + (KtT)²] (shock/fatigue factors). By rigidity: torsional θ = TL/(GJ) limit (e.g. 0.25°/m) and lateral deflection limits.
  • Hollow vs solid: same weight hollow shaft is stronger and stiffer.
  • Keys: sunk (rectangular/square), saddle, feather, Woodruff, splines. Square key checked for shear (τ = 2T/(d·w·l)) and crushing (σc = 4T/(d·h·l)); square key equally strong in both when σc = 2τ.
  • Couplings: rigid (sleeve, flange) and flexible (bushed-pin, Oldham, universal/Hooke's joint). Hooke's joint: speed ratio ω₂/ω₁ = cos α/(1 − cos²θ sin²α); varies between cos α and 1/cos α; double Hooke's joint gives constant velocity if arranged correctly.

Rolling contact bearings

  • Types: deep-groove ball (radial + some axial), angular contact, cylindrical roller (high radial), tapered roller (combined), spherical roller (self-aligning), thrust bearings, needle.
  • Life: L₁₀ = (C/P)ᵏ million revolutions (k = 3 ball, 10/3 roller); C = basic dynamic load rating (90% reliability). Lh = L₁₀ × 10⁶/(60N) hours.
  • Equivalent dynamic load P = XVFr + YFa (V = 1 inner race rotating). Reliability adjustment via Weibull: L/L₁₀ = [ln(1/R)/ln(1/0.9)]1/b, b ≈ 1.17 (bearing-life Weibull slope; 1.5 in some texts).
  • Variable load: Pe = [Σ(Pᵢᵏnᵢ)/Σnᵢ]1/k. Static load rating C₀ for stationary/slow bearings.

Sliding contact (journal) bearings

  • Hydrodynamic lubrication: wedge-shaped oil film builds pressure due to rotation (Petroff, Reynolds equation). Lubrication regimes: boundary, mixed, hydrodynamic (Stribeck curve: friction vs ZN/p).
  • Sommerfeld number S = (r/c)²·μN/p (p = W/(l·d), N in rev/s); design charts (Raimondi–Boyd) give friction coefficient, minimum film thickness, flow, temperature rise. Bearing characteristic number ZN/p must exceed the minimum (≈ 3× critical).
  • Petroff's equation: f = 2π²(μN/p)(r/c). Hydrostatic bearings: external pump supplies pressure (work at zero speed).
  • Bearing materials: babbitt (white metal), bronze, aluminium alloys, PTFE, porous self-lubricating.

Brakes

  • Block (shoe) brake: Fbraking = μRn; torque T = μRnr. Self-energizing if friction moment assists the applied force; self-locking if the required actuating force ≤ 0. Long shoe: equivalent μ′ = 4μ sin θ/(2θ + sin 2θ).
  • Band brake: T₁/T₂ = eμθ; torque (T₁ − T₂)r. Simple, differential (can be self-locking) and band-and-block types.
  • Disc brakes, internal expanding shoe brakes (automobiles). Energy absorbed: KE + PE; temperature rise ΔT = E/(m·c).
  • Dynamometers (absorption: Prony brake, rope brake; transmission types) measure power.

Clutches

  • Friction plate clutch torque T = nμWRm (n = number of friction surfaces).
  • Uniform pressure (new clutch): Rm = (2/3)(R₀³ − Rᵢ³)/(R₀² − Rᵢ²). Uniform wear (worn clutch, pr = constant): Rm = (R₀ + Rᵢ)/2. Uniform wear gives lower torque → safer design assumption. Optimum Rᵢ/R₀ ≈ 0.577 (uniform wear).
  • Cone clutch: T = μW Rm/sin α. Centrifugal clutch: (Fc − Fs)μ r n. Multi-plate clutches for compact, high torque.

Springs

  • Helical compression spring: spring index C = D/d (4–12); Wahl factor K = (4C − 1)/(4C − 4) + 0.615/C (curvature + direct shear); τ = K·8PD/(πd³); deflection δ = 8PD³N/(Gd⁴); stiffness k = Gd⁴/(8D³N).
  • Energy stored U = ½Pδ. Solid length = Nt·d; free length = solid length + max deflection + clearance. Buckling if free length/D is too large. Surge: natural frequency should exceed operating frequency (~15–20×).
  • Leaf (laminated) springs: treat each half as a cantilever of length L carrying W: σ = 6WL/(nbt²), δ = 6WL³/(nEbt³) (n leaves, width b, thickness t); nipping (pre-stressing) equalizes stresses in full-length and graduated leaves. Torsion springs, Belleville (disc) springs, spiral springs.

CAD / CAM and integration

  • CAD: geometric modelling — wireframe (edges only, ambiguous), surface (Bezier, B-spline, NURBS; Bezier curves: degree = control points − 1, global control; B-splines: local control), solid (B-rep and CSG). Parametric and feature-based modelling with constraints; assemblies; drafting; FEA (analysis) and CAE.
  • Transformations: homogeneous 2D/3D matrices for translation, rotation, scaling, reflection, shear; composite = matrix product (order matters). Projections: orthographic, isometric, perspective.
  • Curve representations: explicit, implicit, parametric (preferred). Hermite cubic: needs end points and tangents. Continuity C⁰, C¹, C² and G¹.
  • CAM: generating tool paths and NC code from CAD geometry; post-processors convert to machine-specific G-code. CAPP, NC verification/simulation, robot offline programming.
  • Integration tools/standards: data exchange formats IGES, STEP (ISO 10303, product data), STL (triangulated surface for 3D printing), DXF (2D), Parasolid/ACIS kernels. PDM/PLM systems manage product data and revisions. CAD/CAM integration → CIM with MRP/ERP, FMS, DNC.
  • Group technology (part families, Opitz/MICLASS coding), FMS (flexible manufacturing systems: workstations + automated handling + central computer).

Additive manufacturing (3D printing)

  • Workflow: CAD model → STL (tessellation) → orientation and support generation → slicing into layers → layer-by-layer build → post-processing (support removal, curing, sintering, machining).
  • ASTM/ISO 52900 categories:
    • Material extrusion — FDM/FFF (thermoplastic filament: PLA, ABS, nylon).
    • Vat photopolymerization — SLA (laser), DLP (projector); liquid resin cured by UV; high resolution.
    • Powder bed fusion — SLS (polymers), SLM/DMLS (metals, laser), EBM (electron beam, vacuum).
    • Material jetting — PolyJet (multi-material, colour).
    • Binder jetting — binder into powder (sand moulds, metals, then sintered).
    • Directed energy deposition — LENS, wire-arc AM (repair, large metal parts).
    • Sheet lamination — LOM, ultrasonic AM.
  • Advantages: complex geometries (lattices, internal channels), no tooling, customization, rapid prototyping, part consolidation. Limitations: slow for mass production, anisotropy, surface finish (stair-stepping proportional to layer thickness), size limits, support structures.
  • Applications: prototypes, jigs and fixtures, robot grippers and custom end-effectors, medical implants, aerospace parts, tooling (conformal cooling channels).
